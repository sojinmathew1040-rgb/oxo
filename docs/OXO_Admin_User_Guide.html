Studio Operations Manual

1. Product Catalog Management

Adding & Editing Furniture Designs

Admins can manage the entire luxury catalog directly from the Products Tab or via the Add New Creation button:

  • Add New Creation: Click Add New Creation, fill in product title, category, price, dimensions (Height, Width, Depth/Length in cm), description, specs, materials, and upload high-res showcase photos.
  • Universal Importer: Click Universal Importer, paste any furniture URL or showcase category link to extract product data and photos automatically.
  • Editing Creations: Click the edit icon on any product card in the control center to adjust pricing, update gallery photos, or modify scale graph dimensions.
  • Deleting Items: Click delete to remove obsolete inventory from the store.
2. Brands & Collections Management

Partner Brands, Categories & Swatches

Control how partner brand logos display in the homepage sliding marquee and map custom swatches:

  • Brands: Add partner studio brand names and upload SVG/PNG logos. Logos display smoothly in the storefront marquee.
  • Categories: Add or edit furniture category titles (Sofas, Chairs, Tables, Lighting, Storage, Beds) and assign background accent colors.
  • Materials & Color Palettes: Register new construction materials (Solid Wood, Brushed Metal, Fabric) and custom color swatches with HEX color pickers.
3. Consultation Requests & WhatsApp Integration

Managing Client Consultations

Access client inquiries under Analytics & Inquiries tab:

  • View Inquiries: Review consultation requests submitted by clients from product pages or homepage.
  • Status Update: Toggle inquiry state between Pending, Contacted, and Completed.
  • 1-Click WhatsApp Chat: Click the WhatsApp icon next to any inquiry to instantly start a direct WhatsApp conversation pre-filled with client inquiry details.
4. Settings & Security

WhatsApp Number & Admin Passwords

Configure contact channels and security under the Settings tab:

  • WhatsApp Contact: Update the target admin WhatsApp phone number (with country code, e.g. 919876543210). All storefront inquiry buttons automatically route to this number.
  • Admin Credentials: Change current admin password with secure password hashing.
5. Database Backup & Restoration

Exporting & Importing SQL Database Files

Maintain full data security with 1-click database backup and upload restoration:

  • Backup Database: Click Backup Database in the top header panel or Settings tab. The system compiles all tables into oxo_db.sql and triggers an instant browser download.
  • Import Database: Click Import Database, select any valid .sql backup file, and submit. The system restores schema tables, seeds missing data, and syncs database contents instantly.
