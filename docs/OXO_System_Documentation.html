PHP Script & Component Directory Map

Detailed inventory mapping each PHP script in the codebase to its operational responsibility, parameters, database interaction, and output:

Script Path Module Category Core Responsibility & Functionality Key Actions / Parameters Database Tables Touched
index.php Storefront Home luxury landing page; renders hero banner, partner brand marquee, and featured collections. None (Default view) oxo_products, oxo_brands, oxo_categories
shop.php Storefront Catalog browser with multi-criteria filtering (Category, Brand, Material, Color, Price Range) and dynamic image swapper. GET: category, brand, material, color, search, price_min, price_max oxo_products, oxo_categories, oxo_brands, oxo_materials, oxo_colors
product.php Storefront Product detail showcase featuring 2D scale blueprints, mobile camera AR projection sandbox, and consultation modal form. GET: id (Product ID) oxo_products, oxo_brands, oxo_colors
submit-inquiry.php Storefront API Processes consultation inquiry form submissions and sends notifications. POST: name, email, whatsapp, product_title, message oxo_consultations
about.php Storefront Studio heritage page detailing design philosophy and partner brand portfolio. None oxo_brands
login.php & account.php Client Auth Client authentication portal & profile management dashboard with Google OAuth integration. GET: action, POST: email, password oxo_users
ajax/auth_action.php Client API AJAX endpoint for user registration, password verification, and profile updates. POST: action=login|register|update_profile oxo_users
admin/index.php Admin Studio Master tabbed control center for catalog inventory, analytics, collections, and security. GET: tab=products|analytics|collections|settings All Database Tables
admin/auth.php Admin Auth Authentication guard script; verifies admin session state before executing admin commands. require_admin_login() $_SESSION['admin_logged_in']
admin/import-universal.php Admin Tool 4-Tier URL scraper extracting product specs, batch showcase galleries, and compressing images via PHP GD library. POST: product_url, action=extract_url|batch_confirm oxo_products, oxo_brands, oxo_categories, oxo_materials, oxo_colors
admin/product-editor.php Admin Tool Manual CRUD interface for creating new furniture designs, updating dimensions, and deleting catalog items. GET: id, POST: form_action=add|edit|delete oxo_products, oxo_brands, oxo_categories, oxo_materials, oxo_colors
admin/export-db.php Admin Tool Database exporter generating a complete SQL schema/data dump and streaming direct oxo_db.sql browser download. None (Direct GET trigger) All Database Tables (SHOW TABLES)
admin/import-db.php Admin Tool Database restoration tool processing uploaded .sql files to execute schema updates. POST: sql_file (Multipart upload) All Database Tables
admin/sync-prices.php Admin Tool Live price sync engine re-scraping external source_url locations and updating modified catalog prices. GET: action=sync_all or GET: id=product_id oxo_products
admin/update-inquiry-status.php Admin Tool Updates client consultation inquiry states (Pending, Contacted, Completed). GET: inquiry_id, status oxo_consultations
admin/generate-docs.php Admin Tool Master documentation suite builder generating README.md, developer architecture specs, and admin user manuals. GET: type=developer|admin All Database Tables (SHOW TABLES)
includes/db.php Core Helper PDO connection helper, database auto-creation (oxo_db), table initialization, and column migrations. get_db_connection() All Database Tables
includes/products-db.php Core Helper Data querying functions and static product array fallback data. $PRODUCTS_DB oxo_products
