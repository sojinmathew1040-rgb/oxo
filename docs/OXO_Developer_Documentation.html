Architecture Modules

Universal Product Importer
4-Tier extraction cascade parsing Shopify JSON endpoints, Microdata JSON-LD, OpenGraph tags, and DOM selectors. Features showcase gallery batch importing.
PHP GD Optimization Engine
Automatically resizes and re-compresses raw 3MB-5MB product images into optimized 60KB-150KB web images during import/creation.
Database Exporter & Importer
Single master oxo_db.sql engine. Features 1-click browser download backups (admin/export-db.php) and SQL file restoration (admin/import-db.php).
